# intclass («за минуту») ⚡

Современный русскоязычный справочник структурированных видеоуроков и интерактивных мини-тестов за минуту для 5–9 классов по математике и русскому языку.

## 🚀 Новые возможности (v2.0)

1. **Тёмная и светлая тема (Dark / Light Mode)**:
   - Автоматическое переключение по системным настройкам ОС (`prefers-color-scheme`).
   - Ручной переключатель в шапке и мобильном меню с сохранением в `localStorage`.
   - Оптимизированная контрастность и цвета для ночной учебы.

2. **Мгновенный живой поиск**:
   - Полнотекстовый поиск по урокам, темам, правилам и формулировкам тестов.
   - Горячая клавиша `/` или `Ctrl+K` для быстрого фокуса в строку поиска.
   - Мгновенный сброс и индикация количества найденных результатов.

3. **Система прогресса и сохранение результатов**:
   - Автоматическая фиксация пройденных тестов в `localStorage`.
   - Бейджи «✓ Изучено» на карточках уроков и шкала общего прогресса курса.
   - Всплывающее праздничное конфетти при 100% правильных ответах в тесте.
   - Фильтры каталога: **Все уроки**, **★ Избранное**, **✓ Изученные**, **В процессе**.

4. **Закладки (Избранное) и шеринг**:
   - Кнопка ★ на каждой карточке для сохранения сложных тем перед экзаменом или контрольной.
   - Кнопка копирования прямой ссылки на урок в буфер обмена с мгновенным toast-уведомлением.

5. **Расширенная учебная база (45 уроков)**:
   - Математика: 5–9 классы (дроби, проценты, отрицательные числа, пропорции, линейные и квадратные уравнения, теорема Пифагора, теорема Виета, функции, прогрессии, теория вероятностей).
   - Русский язык: 5–9 классы (фонетика, состав слова, чередование корней, спряжения, приставки ПРЕ/ПРИ, причастные и деепричастные обороты, правописание НЕ, односоставные предложения, СПП, ССП, БСП, структура экзаменационного сочинения).
   - Каждая тема снабжена главным правилом («takeaway») и многоуровневыми мини-тестами с подробными объяснениями.
   - В уроках с видео первое задание теста интерактивное и нарисовано в стиле роликов (`js/tasks.js`): чашечные весы для уравнений, транспортир, числовая ось, координатная плоскость, части окружности и квадрата (a + b)², линия среднего на диаграмме, углы треугольника на прямой и подбор k и b для y = kx + b.

6. **PWA и работа офлайн**:
   - `manifest.webmanifest` для установки как нативное мобильное приложение («Добавить на главный экран»).
   - `sw.js` (Service Worker) с кэшированием статических ресурсов для мгновенной загрузки.

7. **Автоматизированное тестирование**:
   - Набор тестов (`npm test`) на базе нативного тестового раннера Node.js (`node:test`).
   - Проверка целостности данных, уникальности ID, валидности YouTube ID, ответов и объяснений тестов.
   - Каждое интерактивное задание проверяется своим решением, а проверки заданий — на неверных ответах.

## 🎬 Видеоуроки «за минуту» (v2.1)

Десять собственных анимированных видеоуроков (1,5–2 минуты, озвучка на русском) лежат прямо в репозитории в `videos/` и проигрываются встроенным HTML5-плеером — без YouTube и сторонних трекеров:

| Класс | Урок | Видео |
|---|---|---|
| 5 | Уравнения: корень, проверка и неизвестные компоненты | `uravneniya-5.mp4` |
| 5 | Наглядная геометрия: длина, площадь и объём | `geometriya-5.mp4` |
| 6 | Отрицательные числа: модуль, сравнение и правило знаков | `otricatelnye-chisla-6.mp4` |
| 6 | Координатная плоскость | `koordinatnaya-ploskost-6.mp4` |
| 6 | Окружность и круг: число π, длина и площадь | `okruzhnost-i-krug-6.mp4` |
| 6 | Статистика и вероятность: среднее, медиана, мода | `statistika-6.mp4` |
| 7 | Линейные уравнения с одной переменной | `lineinye-uravneniya-7.mp4` |
| 7 | Треугольники: сумма углов и признаки равенства | `treugolniki-7.mp4` |
| 7 | Формулы сокращённого умножения | `fsu-7.mp4` |
| 7 | Линейная функция y = kx + b и её график | `lineinaya-funkciya-7.mp4` |

- Мини-тест открывается автоматически, когда видео досмотрено до конца.
- Фильтр **🎬 С видео** показывает все уроки с видео.
- У уроков, для которых видео ещё нет, вместо чужого ролика показана заглушка «Видео готовится», а тест доступен сразу.
- Варианты ответов в тестах перемешиваются, поэтому верный ответ больше не всегда первый.
- Service Worker не кэширует MP4: видео идут из сети с поддержкой перемотки (HTTP range).

## 🎨 Минималистичный дизайн (v2.2)

- Плоский интерфейс без градиентов, свечений и «пружинных» анимаций: квадратные углы (4 px), тонкие рамки вместо теней, монохромные иконки вместо эмодзи.
- Тёмная тема строится из одного набора цветовых переменных: шапка, меню, профиль, тесты и подсказки корректно перекрашиваются, а `color-scheme` включает тёмные полосы прокрутки и поля ввода.
- Тема применяется в `<head>` до отрисовки страницы, поэтому в тёмном режиме нет вспышки светлой темы.
- Шапка уезжает вверх, когда страницу листают вниз после первого экрана, и возвращается при прокрутке вверх. Отдельной нижней панели нет: всё есть в шапке и меню.
- Для телефонов: компактный первый экран, поля ввода 16 px (iOS не зумит страницу при фокусе), кнопки от 44 px, отступы под «чёлку» и полоску жестов (`safe-area-inset`), выбор класса сеткой 3×2, эффекты наведения только на устройствах с мышью.

## ✨ Цвет и движение (v2.3)

- Палитра 60 / 25 / 15: белый фон, тёмно-синие полосы (раздел «Ориентир по классам», шапка страницы уроков, подвал) и синий акцент (кнопки, выделение «за минуту», подписи, иконки, выбранные элементы, светло-синяя полоса «Выберите предмет»).
- Первый экран занимает весь экран; внизу анимированная подсказка «Листайте вниз»: палец на сенсорных экранах, колесо мыши на компьютере.
- Шапка уезжает при прокрутке вниз после первого экрана и возвращается при прокрутке вверх.
- Нажатия: волна (ripple) расходится от точки касания, кнопка пружинисто «нажимается»; выбранные карточки и звёздочка избранного «подпрыгивают»; тема переключается кругом от кнопки (View Transitions), в остальных браузерах — плавным перетеканием цветов.
- Шрифты: Unbounded для заголовков и Onest для текста, оба с кириллицей.
- Кнопки и выбранные элементы с мягким синим градиентом; на компьютере по кнопке пробегает блик. Постеры видео перекрашены в синюю палитру.
- Шапка прячется при прокрутке вниз (после трети первого экрана) и возвращается при прокрутке вверх на 10 px; мелкие рывки и отскок у края страницы её не дёргают.
- Переходы между страницами плавно затухают (в браузерах с View Transitions).
- Заголовки выезжают из-под маски, блоки поднимаются при прокрутке, карточки уроков появляются каскадом. При «Уменьшить движение» в системе всё это отключается.

## 📂 Структура проекта

```text
├── index.html              # Главная страница: герой, обзор курсов, школьные параллели

│   ├── main.js             # Темы, тосты, мобильное меню, чтение прогресса и профиля, SW
```

## 🧪 Запуск тестов и проверка кода

В проекте нет сторонних runtime-зависимостей. Для запуска тестов нужен установленный Node.js (v18+):

```bash
# Запуск модульных тестов
npm test

# Синтаксическая проверка всех скриптов
npm run check
```

## 🚀 Как изменения попадают на сайт

1. Изменения уходят в ветку `auto/…`, и открывается pull request в `main`.
2. CI запускает проверку `test`: `npm test` и проверку синтаксиса.
3. После успешной проверки PR сливается в `main`, ветка удаляется.
4. GitHub Pages пересобирает сайт. Файл `.nojekyll` отключает Jekyll, поэтому сборка короче.

## ✏️ Добавить новый видеоурок

1. Положите ролик в `videos/имя.mp4`, а постер (кадр 16:9, ~960 px) — в `videos/posters/имя.jpg`.
2. Откройте `js/lessons.js` и добавьте объект в массив `LESSONS`:

```js
{
  id: "math-7-5",
  subject: "math", // "math" | "russian"
  grade: "7",      // "5" | "6" | "7" | "8" | "9"
  topic: "Название темы",
  title: "Полный заголовок урока",
  description: "Краткое текстовое описание видео.",
  takeaway: "Главное правило или формула в одном предложении.",
  video: {                      // собственное видео из папки videos/
    src: "videos/imya.mp4",
    poster: "videos/posters/imya.jpg",
    duration: "1:35"
  },
  // videoId: "xxxxxxxxxxx",    // или 11-значный ID ролика с YouTube; без видео карточка покажет «Видео готовится»
  quiz: [
    {
      question: "Вопрос теста по теме?",
      options: ["Вариант 1 (верный)", "Вариант 2", "Вариант 3"],
      answer: 0, // Индекс верного ответа в options (на экране варианты перемешиваются)
      explanation: "Пояснение, почему этот ответ правильный."
    }
  ]
}
```
