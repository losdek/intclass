# intclass («за минуту») ⚡

Современный русскоязычный справочник структурированных видеоуроков и интерактивных мини-тестов за минуту для 5–9 классов по математике и русскому языку.

## 🚀 Новые возможности (v2.0)

1. **Тёмная и светлая тема (Dark / Light Mode)**:
   - Автоматическое переключение по системным настройкам ОС (`prefers-color-scheme`).
   - Ручной переключатель в шапке и мобильном меню с сохранением в `localStorage`.
   - Оптимизированная контрастность и цвета для ночной учебы.

2. **Мгновенный живой поиск**:
   - Полнотекстовый поиск по урокам, темам, правилам и формулировкам тестов.
   - Горячая клавиша `/` или `Ctrl+K` для быстрого фокуса в строку поиска.
   - Мгновенный сброс и индикация количества найденных результатов.

3. **Система прогресса и сохранение результатов**:
   - Автоматическая фиксация пройденных тестов в `localStorage`.
   - Бейджи «✓ Изучено» на карточках уроков и шкала общего прогресса курса.
   - Всплывающее праздничное конфетти при 100% правильных ответах в тесте.
   - Фильтры каталога: **Все уроки**, **★ Избранное**, **✓ Изученные**, **В процессе**.

4. **Закладки (Избранное) и шеринг**:
   - Кнопка ★ на каждой карточке для сохранения сложных тем перед экзаменом или контрольной.
   - Кнопка копирования прямой ссылки на урок в буфер обмена с мгновенным toast-уведомлением.

5. **Расширенная учебная база (40 уроков)**:
   - Математика: 5–9 классы (дроби, проценты, отрицательные числа, пропорции, линейные и квадратные уравнения, теорема Пифагора, теорема Виета, функции, прогрессии, теория вероятностей).
   - Русский язык: 5–9 классы (фонетика, состав слова, чередование корней, спряжения, приставки ПРЕ/ПРИ, причастные и деепричастные обороты, правописание НЕ, односоставные предложения, СПП, ССП, БСП, структура экзаменационного сочинения).
   - Каждая тема снабжена главным правилом («takeaway») и многоуровневыми мини-тестами с подробными объяснениями.

6. **PWA и работа офлайн**:
   - `manifest.webmanifest` для установки как нативное мобильное приложение («Добавить на главный экран»).
   - `sw.js` (Service Worker) с кэшированием статических ресурсов для мгновенной загрузки.

7. **Автоматизированное тестирование**:
   - Набор тестов (`npm test`) на базе нативного тестового раннера Node.js (`node:test`).
   - Проверка целостности данных, уникальности ID, валидности YouTube ID, ответов и объяснений тестов.

## 📂 Структура проекта

```text
├── index.html              # Главная страница: герой, обзор курсов, школьные параллели
├── lessons/
│   └── index.html          # Библиотека уроков: поиск, фильтры, 3 шага, плеер и тесты
├── css/
│   └── style.css           # Цветовая система (светлая/тёмная), адаптив, анимации, печать
├── js/
│   ├── main.js             # Темы, тосты, мобильное меню, чтение прогресса и профиля, SW
│   └── lessons.js          # База 40 уроков, плеер, тесты, поиск, закладки, конфетти
├── manifest.webmanifest    # Конфигурация PWA для смартфонов и планшетов
├── sw.js                   # Service Worker для офлайн-кэширования
├── test/
│   └── lessons.test.js     # Набор модульных тестов
└── 404.html                # Страница редиректа для чистых путей GitHub Pages
```

## 🧪 Запуск тестов и проверка кода

В проекте нет сторонних runtime-зависимостей. Для запуска тестов нужен установленный Node.js (v18+):

```bash
# Запуск модульных тестов
npm test

# Синтаксическая проверка всех скриптов
npm run check
```

## ✏️ Добавить новый видеоурок

Откройте `js/lessons.js` и добавьте объект в массив `LESSONS`:

```js
{
  id: "math-7-5",
  subject: "math", // "math" | "russian"
  grade: "7",      // "5" | "6" | "7" | "8" | "9"
  topic: "Название темы",
  title: "Полный заголовок урока",
  description: "Краткое текстовое описание видео.",
  takeaway: "Главное правило или формула в одном предложении.",
  videoId: "WUvTyaaNkzM", // 11-значный ID ролика из YouTube
  quiz: [
    {
      question: "Вопрос теста по теме?",
      options: ["Вариант 1 (верный)", "Вариант 2", "Вариант 3"],
      answer: 0, // Индекс верного ответа (начиная с 0)
      explanation: "Пояснение, почему этот ответ правильный."
    }
  ]
}
```
